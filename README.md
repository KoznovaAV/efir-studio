# EFIR Studio

EFIR Studio собирает короткие ролики из сцен. Рабочая ветка v0.2 добавляет планы сценария через локальный Ollama, редактирование в Tk, историю SQLite, очередь озвучки Piper и экспорт FFmpeg. В сцену можно импортировать свой клип, изображение и озвучку. Ручная сборка и экспорт работают после установки Python и FFmpeg без учётной записи.

v0.2 проходит приёмку. Зафиксированные прогоны и проверка качества AI описаны в [чек-листе v0.2](docs/releases/v0.2/RELEASE_CHECKLIST.md). Установка движков и веса отделены от EFIR. [Подключение движков](docs/releases/v0.2/USER_GUIDE.md).

## Запуск на Windows

Нужны Python 3.11+ с Tk для настольного интерфейса и [сборка FFmpeg](https://ffmpeg.org/download.html#build-windows) с `libx264` и AAC. Из корня репозитория запустите PowerShell. Если FFmpeg уже в PATH, достаточно второй строки. Настольное приложение и CLI используют стандартную библиотеку Python.

```powershell
$env:EFIR_FFMPEG = 'D:\Tools\ffmpeg\bin\ffmpeg.exe'
python -m efir desktop
```

1. Создайте проект SQLite и выберите формат. Доступны 9:16, 16:9 и 1:1. Полное разрешение вертикального экспорта — 1080×1920 при 25 кадрах/с. Существующий JSON-проект открывается напрямую. Кнопка **Мигрировать v0.1** копирует проект в новый каталог.
2. Добавьте клипы или изображения, задайте длительность и порядок. Для клипа можно указать начало и сохранить его звук. Добавьте файл озвучки, субтитр и заметки об источнике, модели или промпте. Режим `contain` сохраняет весь исходный кадр с полями, `cover` центрирует и обрезает края.
3. Выберите **Экспорт MP4** и откройте готовый файл из списка задач. Черновое разрешение вдвое меньше по каждой оси. Для финального экспорта снимите флажок. MP4 содержит переключаемую дорожку субтитров при наличии текста. Отдельный SRT можно открыть в редакторе или загрузить в сервис публикации.
4. Чтобы заменить материалы, откройте проект и выберите сцену. При повторном экспорте статус показывает число сцен из кэша и число заново закодированных сцен. Изменение названий, порядка или субтитров не требует перекодирования видео.

## CLI

```powershell
python -m efir init '.\Первый выпуск' --sqlite --title 'Первый выпуск' --aspect 9:16
$scene = python -m efir add '.\Первый выпуск' --title 'Вступление' --visual '.\вступление.mp4' --duration 5.2 --voice '.\реплика.wav' --caption 'Мы в эфире.'
python -m efir add '.\Первый выпуск' --title 'Финал' --visual '.\финал.mp4' --duration 3.6 --source-audio
python -m efir export '.\Первый выпуск' '.\выпуск.mp4'
python -m efir edit '.\Первый выпуск' $scene --visual '.\вступление-дубль2.mp4'
python -m efir export '.\Первый выпуск' '.\выпуск.mp4' --overwrite
python -m efir srt '.\Первый выпуск' '.\выпуск.srt'
```

`list` выводит идентификаторы сцен. Подкоманды `move` и `remove` меняют порядок и состав. `init` без флага сохраняет формат v0.1 для прежних скриптов. [Команды чата, очереди и миграции](docs/releases/v0.2/USER_GUIDE.md).

## Материалы и сохранение

- Изображения: PNG, JPEG. Видео: MP4, MOV, MKV, WebM со стандартными потоками. Звук: WAV, MP3, FLAC, M4A. Поддержка декодирования зависит от сборки FFmpeg.
- Для короткого клипа последний кадр удерживается до конца сцены. Аудио приводится к длительности сцены обрезкой или дополнением тишиной. При одновременной озвучке и включённом звуке клипа используется базовый микс с ослабленным звуком клипа.
- В первой версии один субтитр на сцену. Для тонкой синхронизации после экспорта SRT используйте редактор субтитров.
- Для SQLite используйте **Переносимая копия** или `python -m efir portable ИСХОДНЫЙ НОВЫЙ`. Копируются БД, связанные материалы и MP4 завершённых задач. Для v0.1 переносите папку с `project.json` и `assets`. [Миграция и восстановление](docs/releases/v0.2/MIGRATION_GUIDE.md).
- Генерация изображений и видео выполняется во внешних инструментах. Русскую озвучку можно импортировать или поставить в очередь Piper. [Исследование](docs/market-research/README.md).

## Проверки

```powershell
$env:PYTHONUTF8 = '1'
$env:EFIR_TEST_DESKTOP = '1'
python -m unittest discover -s tests -v
```

При наличии FFmpeg тесты кодируют видео и проверяют конечный MP4. Настольный тест включается переменной `EFIR_TEST_DESKTOP` на компьютере с графической сессией. Результаты и продолжение работы описаны в [состоянии проекта](docs/STATUS.md).
