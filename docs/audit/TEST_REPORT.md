## Границы

- Проверены черновой и полный CPU-экспорт, черновой landscape и вертикальный профиль. Тест задержанного аудио проверяет начало сигнала после обрезки. Губная синхронизация реальной записи не измерялась.
- Негативные проверки включают повреждённый вход, изменённый/недопустимый media reference, отказ при устаревшем сохранении и отмену. Предыдущий MP4 сохраняется байт-в-байт. Все разрешённые контейнеры, UNC, исчерпание диска, крах приложения и враждебные медиа не прогонялись.
- Проверены попадания в кэш после перестановки, правки субтитров, смены длительности и визуала. Изменение голоса, кадрирования, выходного профиля и подписи FFmpeg требует отдельной параметризованной матрицы. Численное покрытие кода не измерялось.
- Длинные прогоны, параметры MP4, версии пакетов конкурентов и ограничения замеров приведены в [практическом сравнении](../research/PRACTICAL_COMPARISON.md).
- Исправления проверены на Windows. Существующий workflow автоматически запускает pull request jobs для PR с базой `main`. PR аудита направлен в ветку v0.1, локальный прогон Linux для исправлений не выполнялся.
