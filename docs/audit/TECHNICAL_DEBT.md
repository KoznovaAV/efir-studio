# Технический долг v0.1

| Приоритет | Задача | Критерий закрытия |
|---|---|---|
| P1, закрыто | Целостность кэша и строгая ошибка FFmpeg | Повреждённый сегмент перестраивается, валидный переиспользуется, прежний MP4 переживает отказ. |
| P1, закрыто | Задержка исходного звука | Тест отложенного аудио с trim подтверждает тишину до ожидаемого начала и сигнал после. |
| P1, закрыто | Согласованный снимок сцен | Правка после начала сборки не подменяет текст и длительность готового экспорта. |
| P1, закрыто | Пропорции анаморфного источника | Регрессия SAR 2:1 подтверждает правильные поля contain. Cover использует тот же DAR. |
| Проверка пройдена | Параллельный ffconcat | Склейка и субтитры двух конкурирующих сборок относятся к правильной ревизии. |
| P0 перед публичным выпуском | Длительный экспорт и реальные форматы | Матрица VFR, SAR, rotate, разных частот звука, нескольких дорожек, отсутствия исходного звука и trim за концом клипа. |
| P0 перед v0.2 | Персистентная очередь и одно выходное назначение | Одна контролируемая публикация на путь, отказ устаревшей сборки, проверенное восстановление после рестарта. |
| P1 | Кэш и исчерпание диска | Обратная связь о диске, ограничение хранения, безопасная очистка невостребованных файлов, метрики дублирования и восстановления staging. |
| P1 | Расширенная звуковая модель | Отдельный фон выпуска, уровни, диапазоны реплик и несколько cues на сцену. Выборочное обновление WAV и субтитров проверяется по ключам. |
| P1 | Диагностика и пути Windows | Проверка кодеков, каталога и причин отказа. Фиксированная версия FFmpeg и тесты доступа, Unicode, длинных и сетевых путей. |
| P1 | Перенос генеративной истории | Миграция v1, новая схема ревизий, проверенная копия без абсолютных путей, история референсов и промптов. |
| P1 | Сопоставимые пользовательские пилоты | Два оператора и одинаковые задачи. Измерены время, ручные действия, ошибки и перенос в EFIR, Velorn и Kdenlive. |
| P2 | Лицензии и упаковка | Документированы версия FFmpeg, флаги сборки, лицензии моделей/голосов и обновление. |
