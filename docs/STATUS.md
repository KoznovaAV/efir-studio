# Состояние EFIR Studio

**23 ноября 2026 года. v0.1, ветка `codex/efir-studio-v0.1`.**

Решение COMPOSE принято после [исследования](market-research/README.md). [ADR](architecture/0001-scene-assembly.md) фиксирует контракт переносимого проекта, ключ кэша сцены и план проверки. [README](../README.md) содержит запуск интерфейса и команды. Первый этап охватывает ручной импорт готовых AI/камерных материалов, отдельную озвучку, сцены, субтитры и CPU MP4. Пакет моделей и готовый установщик отсутствуют.

## Проверено в этой сессии

- Windows 11, Python 3.13.16 / Tk 8.6, FFmpeg 7.1 essentials. Все 11 локальных тестов прошли, включая настольное окно Tk с фоновым экспортом, CLI, повторное открытие, изменённый исходник, сохранение поверх устаревшей ревизии, кириллицу в пути и субтитрах, наличие движения и аудио в декодированном MP4, короткий клип, отказ на повреждённом входе и отмену.
- Отдельный полноразмерный прогон на трёх коротких синтетических клипах с WAV от уже установленного Microsoft Irina Desktop. Для результата после правки проверены 1080×1920, 345 кадров при 25 кадрах/с, AAC-аудиопоток и извлечённый кириллический SRT. WAV использован как импорт, качество TTS и художественный результат не оценивались.

| Полноразмерный прогон | Сцен перекодировано | Сцен из кэша | Время одного запуска |
|---|---:|---:|---:|
| Первая сборка 14 с | 3 | 0 | 2,056 с |
| Повтор без изменений | 0 | 3 | 0,471 с |
| Правка сцены 2, итог 13,8 с | 1 | 2 | 0,912 с |

Это время одного прогона включая запуск CLI. Закономерность для реальных клипов, 90–120 секунд и сложных кодеков предстоит измерить. Локальные материалы проверки в `.efir-local/windows-smoke-162340/` и исключены из Git.

## Возобновление

1. Переключиться на рабочую ветку. Из корня проекта запустить `python -m efir desktop`. Если FFmpeg недоступен в PATH, указать путь через `EFIR_FFMPEG`.
2. Прочитать [протокол](market-research/BENCHMARK_PLAN.md), затем собрать свой 90–120-секундный 9:16 ролик и воспроизвести три правки в Velorn и Kdenlive. Сравнить время, перенос проекта и число ручных действий.
3. При подтверждённом выигрыше проверить один легковесный локальный адаптер. Сначала сравнить CPU TTS либо отдельный ComfyUI workflow. Версии и требования записать до эксперимента. Загрузки больших моделей и платные вызовы в текущей сессии не проводились.
