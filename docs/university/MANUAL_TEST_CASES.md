# Ручное тестирование Tk

Прогон 26 ноября 2026 года в реальном окне Windows 11. Использован отдельный синтетический проект с клипом и PNG по 1 секунде. Взаимодействие выполнялось через штатные Tk и Windows-диалоги. Проверочный MP4 затем открыт FFmpeg для чтения субтитров.

## Стенд

Запустите из корня репозитория `python -m efir desktop` с рабочим FFmpeg. Используйте отдельный каталог. Подготовьте десятисекундный или более короткий MP4, PNG и WAV, либо сгенерируйте их с `testsrc2`, `color` и `sine`, как в [CLI E2E](E2E_TEST_CASE.md). Для состояний с кэшем сначала экспортируйте две сцены 9:16.
