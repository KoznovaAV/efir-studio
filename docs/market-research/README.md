# Исследование EFIR Studio

Срез на 23 ноября 2026 года. Решение **COMPOSE**. Первая версия — локальная сборка сцен из готовых материалов с точечным перекодированием. У широкой AI-студии уже есть прямые конкуренты. У узкой сборки есть проверяемая польза, даже если этот ноутбук не генерирует видео локально. Спрос на отдельный продукт остаётся гипотезой.

## Метод

Первичные источники — репозитории, фиксированные коммиты, код, релизы, документация разработчиков, model cards и условия провайдеров. Заявления авторов и сообщения пользователей подписаны как таковые. Учитывались наличие режима сборки без моделей, независимость от платных API, воспроизводимость проекта и применимость к Windows с 6 ГБ VRAM. Релизы и режимы конкурентов проверялись по источникам. Их установка, инференс и сравнительный тест UX в эту сессию не проводились.

В матрице Supported означает документированную функцию, Partial — ограниченный сценарий, Plugin — внешний движок или рецепт, Paid — платный путь, Unsupported — функция вне продуктового контура, Unknown — отсутствуют достаточные данные. Импорт готового видео отмечен отдельно от T2V/I2V. Для аудио сравнивались доступные пути работы с голосом. Качество русского не выведено из наличия кнопки TTS.

Баллы 0–5 — экспертная шкала. Ноль означает отсутствие функции в данном продукте, 1–2 — существенные ограничения, 3 — частично подходит, 4 — подходит с небольшими ограничениями, 5 — прямое подтверждение по выбранному критерию. UX в этой оценке определяется полнотой документированного пути и числом внешних шагов. Оценка кода опирается на наблюдаемые границы модулей и тесты. Unknown исключён из числителя и знаменателя. Таблица показывает его вес и уровень уверенности отдельно. Расширенная аппаратная модель повышает веса локальности и слабого железа и снижает веса BYOK и агентов.

Лидеры общей модели — Nomi 4,39, Velorn 4,30, IV Studio 4,11. При приоритете доступного железа лидирует Velorn 4,32, затем Kdenlive 4,07 и Nomi 4,06. Это меняет выбор сравнительного эталона, но сохраняет вывод о собственном узком ядре сборки. Qamba подтверждает, что кэш отдельных клипов уже существует на рынке.
