# Пользовательские проблемы и гипотезы

Собраны 23 ноября 2026 года. Это качественные сигналы из первичных обсуждений и публичных воспроизведений. Выборка не даёт частоты проблем или размера рынка.

- Память под Windows — наиболее сильный повторяющийся сигнал. В ComfyUI есть сообщения о расходе RAM/pagefile и регрессиях CUDA/offload на разных конфигурациях. FramePack имеет отдельный отчёт с 8 ГБ VRAM и зависанием на первом сэмплировании. Заявленные 6 ГБ остаются исходной гипотезой для RTX 4050. [ComfyUI 8298](https://github.com/Comfy-Org/ComfyUI/issues/8298), [ComfyUI 13210](https://github.com/Comfy-Org/ComfyUI/issues/13210), [ComfyUI 15255](https://github.com/Comfy-Org/ComfyUI/issues/15255), [FramePack 774](https://github.com/lllyasviel/FramePack/issues/774).
- Установка и узлы увеличивают число решений до первого результата. Документация ComfyUI выделяет проблемы CUDA, перенос моделей, сторонние ноды и mirror settings. В обсуждении Pinokio пользователи описывают разные исходы установки. Признак трения есть, его частота неизвестна. [Troubleshooting ComfyUI](https://github.com/Comfy-Org/docs/blob/main/troubleshooting/overview.mdx), [обсуждение установки](https://www.reddit.com/r/comfyui/comments/1wi7ntx/do_any_of_you_use_pinokio_thoughts_opinions/).
- Связность рендера и редактора поддерживается несколькими независимыми продуктовыми реализациями. Qamba кеширует клипы, Velorn хранит редакторский проект и workflow. Публикации автора Velorn полезны как описание процесса работы, без независимого подтверждения спроса. [Рендер Qamba](https://github.com/qamba-labs/qamba-studio-oss/blob/c16a704cffd3a3790c5dc70e67b99bd388c8c552/worker/handlers/render.py), [обсуждение Velorn](https://www.reddit.com/r/comfyui/comments/1usefmi/comfystudio_is_now_velorn_big_update_since_my/).
- Оплата по моделям и секундам усложняет прогноз стоимости итераций. Это свойство опубликованных тарифов. Пользовательская частота отказа от таких сервисов неизвестна. [fal](https://fal.ai/docs/documentation/model-apis/pricing), [Runway](https://runway.com/pricing).
- Русская речь, натуральное движение, перенос исходников и восстановление очереди входят в полезный сценарий пилота. По найденным материалам отсутствует достаточная выборка независимых отзывов, чтобы ранжировать их по частоте у русскоязычных авторов.

| Гипотеза | Текущая уверенность | Проверка |
|---|---|---|
| H1. Chat-first важнее числа функций | Низкая. Nomi, Qamba и Velorn подтверждают наличие, данных о превосходстве UX нет | Сравнить число действий и время трёх сцен с чатом и в редакторе |
| H2. Начальная настройка генеративного стека сложна | Средняя. Есть troubleshooting и расходящиеся пользовательские исходы | Записать отказы и ручные шаги Windows Portable |
| H3. 6 ГБ — существенный барьер видео | Высокая для изученных официальных конфигураций; отдельные low-VRAM пути остаются | Замерить RAM, VRAM и время короткого I2V |
| H4. Local + BYOK востребован | Средняя по предложению, низкая по спросу | На пяти пилотах выяснить, какие режимы действительно запускают |
| H5. Автоматизация многосценных роликов экономит время | Средняя. Сценарий встречается у разных проектов | Сравнить первое сборочное время и три последовательных правки |
| H6. Библиотека персонажей повышает качество | Средняя для повторного выбора референса, низкая для визуальной консистентности | Оценка серии из шести шотов с единым и изменяемым референсом |
| H7. Редактор совместим с ассистентом | Высокая технически. Nomi и Velorn подтверждают обе поверхности | Проверить восстановление после трёх агентских и трёх ручных правок |
| H8. Выборочный рендер уменьшает перекодирование | Высокая технически. Есть код Qamba и тест EFIR | Сравнить проходы с холодным и тёплым кэшем |
| H9. Аппаратные пресеты уменьшают неудачные запуски | Средняя. LTX Desktop применяет пороги; эффективность пресетов неизвестна | Отдельно измерить отказы на 6 ГБ и 8–12 ГБ |
| H10. Есть отдельная ниша для EFIR | Низкая по рыночному спросу, средняя по техническому сценарию | Сравнить EFIR, Velorn и Kdenlive на одном проекте с готовыми материалами |
