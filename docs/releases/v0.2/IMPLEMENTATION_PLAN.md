# План реализации v0.2

| Этап | Результат в рабочей ветке | Проверка |
|---|---|---|
| A | SQLite с миграциями, история, импорт v0.1, проверяемые копии | Два конкурентных редактора, сохранность JSON, контроль хешей |
| B | Персистентная очередь, аренда, отмена, ограниченный повтор, публикация по снимку | Повтор после выхода процесса, конфликт реплики, остановка, общий кэш |
| C | Ollama через loopback и JSON Schema, предпросмотр и подтверждение | Контракт HTTP, ошибки схемы, отклонение, конфликт ревизии |
| D | Внешний CPU-процесс Piper, WAV и рецепт, ручной импорт | Контракт процесса, отказ движка и кэш, реальный голос ожидает проверки |
| E | Tk с проектами, чатом, сценами и задачами | Автоматические пользовательские маршруты в Tk |
| F | Авторский черновик «ЭФИР 03:33» с импортом голоса Windows | Два экспорта, проверка потоков, перенос, точечная правка |

Ветка основана на `codex/efir-v01-qa-ci`. v0.2 развивается в отдельном GitHub PR. Учебный проект v0.1 и его конфигурация защищённого раннера ведутся отдельно. Следующий шаг приёмки после подготовки моделей описан в [чек-листе](RELEASE_CHECKLIST.md).
