# Известные ограничения v0.2

- Качество дикторской речи оценивают два независимых слушателя. Исправность PCM, тайминг, скорость и RTF подтверждают работу синтеза. [Протокол](TTS_LISTENING_PROTOCOL.md).
- Модель может выбрать неверное действие даже при валидном JSON. EFIR показывает план и привязывает его к ревизии. Пользователь подтверждает изменения после проверки. [Корпус и результаты](LLM_EVALUATION.md).
- Настройка автоматизирована для Windows AMD64 и CPython 3.13. Для Windows ARM64 и других версий Python нужны совместимые wheel.
- Переносимый проект включает медиа и историю. Движки устанавливаются отдельно на целевой машине. [Руководство](USER_GUIDE.md).
- MP4 содержит переключаемые субтитры, SRT сохраняется отдельно. Если площадка игнорирует дорожку, субтитры нужно вшить отдельным проходом или загрузить SRT в интерфейсе площадки.
- Перед упаковкой движков вместе с приложением нужно проверить условия распространения. [Обязательства при распространении](THIRD_PARTY_LICENSES.md).
