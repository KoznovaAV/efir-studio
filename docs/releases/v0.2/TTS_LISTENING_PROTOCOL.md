# Слепая оценка русского голоса

Набор содержит девять оригинальных WAV Denis без обработки и два пустых CSV. Два русскоязычных слушателя работают независимо. Каждый получает только WAV и свой бланк. Исходные реплики и оценки другого человека остаются у организатора.

1. Прослушайте записи T01–T09 в удобном порядке при одинаковой громкости. Можно повторно прослушать фрагмент.
2. Запишите услышанные слова в столбец transcript. Сомнительный фрагмент обозначьте многоточием. Если услышанное число или сокращение отличается от ожидаемого, запишите, как оно прозвучало.
3. Отдельно отметьте произношение имён, чисел и сокращений в pronunciation, а ударения в stress.
4. Оцените естественность в naturalness целым числом от 1 до 5. Один балл означает очень неестественное звучание, три — речь достаточно естественна для понимания, пять — естественная дикторская речь. Остальные наблюдения укажите в comments.
5. Передайте заполненный CSV организатору. Сохраните идентификаторы записей, заголовки столбцов и разделитель «точка с запятой».

## Расчёт после получения двух бланков

```powershell
python scripts/score_listening.py reports/v02-ai-listening/references.json PATH_К_БЛАНКУ_1 PATH_К_БЛАНКУ_2
```

Скрипт приводит регистр к нижнему, заменяет «ё» на «е», удаляет пунктуацию при разбиении на слова и применяет зафиксированные эквиваленты для чисел и произнесённых аббревиатур. WER равен сумме вставок, удалений и замен, делённой на число слов в эталоне. Разборчивость вычисляется как max(0, 1 − WER) × 100%. Порог для каждого слушателя — 95% разборчивости и медиана естественности от 3/5. Имена, числа и ударения рассматриваются отдельно по комментариям. Исходные формы и персональные данные хранятся локально.
