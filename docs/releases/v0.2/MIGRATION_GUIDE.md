# Миграция и перенос

Закройте редактор проекта v0.1 на время копирования. Укажите новый каталог вне исходного проекта. EFIR проверит ссылки и хеши, скопирует материалы, сохранит тот же порядок, идентификаторы и настройки сцен, после чего опубликует новый каталог.

```powershell
python -m efir migrate '.\Выпуск-v01' '.\Выпуск-v02'
python -m efir list '.\Выпуск-v02'
python -m efir history '.\Выпуск-v02'
python -m efir desktop '.\Выпуск-v02'
```

В случае ошибки исходный `project.json` и каталог `assets` остаются доступными. Проект v0.1 открывается старым CLI. Исправьте указанный медиафайл повторным импортом в старый проект и повторите миграцию в свободный каталог.

```powershell
python -m efir portable '.\Выпуск-v02' '.\Выпуск-копия'
python -m efir desktop '.\Выпуск-копия'
```

Копия включает все ревизии, утверждения плана, очередь и связанные материалы. MP4 из завершённых задач входит в копию. Внешние MP4 и SRT, которые были сохранены по вручную заданному пути, переносите отдельно. На втором компьютере установите FFmpeg для рендера и настройте те же файлы Piper для ожидающих задач синтеза.
