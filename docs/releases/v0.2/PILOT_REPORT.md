# ЭФИР 03:33 · Контрольная лента

Черновик в жанре аналогового хоррора с комедийными элементами. Шесть сцен по 16 секунд. Графика рисуется скриптом, фон синтезируется из радиошума и гула, сценарий написан для этого выпуска. Черновая речь получена из установленного Microsoft Irina Desktop. Права на исходники графики, текста и звуковой композиции не зависят от чужих видео.

| Сцена | Экран | Сюжет |
|---|---|---|
| 1 | Служебный канал | Часы застывают на 03:33 |
| 2 | Помеха | Чайник выходит в эфир без разрешения |
| 3 | Камера 04 | Дверь открывается в тот же коридор |
| 4 | Аудиоархив | Запись завтрашнего выпуска запрещает читать саму себя |
| 5 | Протокол тишины | Приёмник называет фамилии |
| 6 | Повтор записи | Выпуск возвращается к началу |

Команда создаёт медиа, проект SQLite, два экспорта и переносимую копию.

```powershell
pwsh -File scripts/pilot.ps1 -Output 'reports/efir-0333-new' -Ffmpeg 'D:\Tools\ffmpeg\bin\ffmpeg.exe'
```

Декодированный MP4 содержит 2400 последовательных кадров в 1080×1920 при 25 fps. Встроенные и внешние субтитры содержат шесть интервалов по 16 секунд. Для каждого фрагмента временной сдвиг речи измерен корреляцией декодированного микса с исходным WAV в окне ±60 мс. Пик пришёлся на нулевой сдвиг во всех шести сценах с коэффициентом 0,9997–0,9999. После импорта нового WAV второй сцены экспорт переиспользовал пять сцен. SQLite-копия открылась в CLI. Хеш финального MP4 совпал с выходом в копии. Измерения времени приведены в [отчёте ресурсов](RESOURCE_BENCHMARK.md).

Субтитры в этом черновике представлены короткими экранными фразами по 16 секунд, также доступен SRT. На отдельном тестовом кадре с отметки 00:18 видна строка «Чайник в эфире» с контуром и отступом от служебных надписей. Дорожка итогового MP4 переключаемая. Для площадок без импорта SRT понадобится отдельный экспорт с вшитыми субтитрами. Художественная редактура, естественность голоса и экспортный профиль отдельных площадок оцениваются отдельно.
