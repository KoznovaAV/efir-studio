# ЭФИР 03:33 · Контрольная лента

Черновик в жанре аналогового хоррора с комедийными элементами. Шесть сцен по 16 секунд. Графика рисуется скриптом, фон синтезируется из радиошума и гула, сценарий написан для этого выпуска. Черновая речь получена из установленного Microsoft Irina Desktop. Права на исходники графики, текста и звуковой композиции не зависят от чужих видео.

| Сцена | Экран | Сюжет |
|---|---|---|
| 1 | Служебный канал | Часы застывают на 03:33 |
| 2 | Помеха | Чайник выходит в эфир без разрешения |
| 3 | Камера 04 | Дверь открывается в тот же коридор |
| 4 | Аудиоархив | Запись завтрашнего выпуска запрещает читать саму себя |
| 5 | Протокол тишины | Приёмник называет фамилии |
| 6 | Повтор записи | Выпуск возвращается к началу |

Команда создаёт медиа, проект SQLite, два экспорта и переносимую копию.

```powershell
pwsh -File scripts/pilot.ps1 -Output 'reports/efir-0333-new' -Ffmpeg 'D:\Tools\ffmpeg\bin\ffmpeg.exe'
```

Первый локальный MP4 в полном профиле содержит 2400 кадров при 25 fps. Внешний SRT содержит шесть интервалов от 00:00 до 01:36. После импорта нового WAV второй сцены экспорт переиспользовал пять сцен. SQLite-копия открылась в CLI. Хеш финального MP4 совпал с выходом в копии. Измерения времени приведены в [отчёте ресурсов](RESOURCE_BENCHMARK.md).

Критерий прохождения маршрута «чат → утверждённый сценарий → Piper → выборочный повтор» требует реальных движков. Этот черновик использует вручную собранный сценарий и импортированный голос. Контрактные тесты отдельно проверяют подтверждение плана, выборочную генерацию и сохранение ревизий.
