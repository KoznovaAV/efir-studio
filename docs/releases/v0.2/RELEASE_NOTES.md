# EFIR Studio v0.2 · черновик релиза

EFIR Studio предлагает локальные планы через Qwen3, сохраняет изменения в SQLite после подтверждения, синтезирует реплики Denis в очереди и экспортирует видео через FFmpeg. История позволяет отменять правки и продолжать работу после перезапуска. Ручное редактирование работает через Tk и CLI.

В этой итерации добавлены воспроизводимая настройка движков на Windows, локальная диагностика, проверка фактических результатов сцен и бланки слепого прослушивания. Формат сценария Ollama задаёт длительности в секундах. EFIR переводит их в кадры и валидирует перед сохранением.

Статус выпуска зависит от [чек-листа приёмки](RELEASE_CHECKLIST.md). Изменения собраны в [черновике PR №4](https://github.com/KoznovaAV/efir-studio/pull/4).

В v0.3 запланированы визуальные референсы персонажей, проверяемые рецепты генерации медиа и пакет передачи проекта в редактор. [Дорожная карта](../../roadmap/PRODUCT_ROADMAP.md).
