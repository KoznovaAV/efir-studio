# Проверка моделей Ollama

На момент начала работы Ollama отсутствовал в PATH, стандартной папке установки и на локальном порту 11434. Веса не обнаружены по стандартному пути. Контракт проверен на локальном HTTP-сервере с ответами заглушки. Результаты по языку, качеству планов и оборудованию пока открыты.

| Кандидат | Публичные метаданные | Причина для проверки |
|---|---|---|
| Qwen3 4B Q4_K_M | 2 497 293 931 байт слоёв и конфигурации, Apache 2.0, тег `qwen3:4b` | Текстовый кандидат с меньшим объёмом, чем Qwen3.5 4B. Первый для проверки на 6 ГБ VRAM |
| Qwen3.5 4B Q4_K_M | 3 324 173 934 байта слоёв и конфигурации, Apache 2.0, тег `qwen3.5:4b-q4_K_M` | Более свежий кандидат при недостаточном качестве Qwen3. Требует дополнительной проверки памяти и схемы |
| Qwen3 8B Q4_K_M | 5,2 ГБ по каталогу, Apache 2.0, тег `qwen3:8b` | Для сравнения качества на машине с большим запасом VRAM. Веса на целевой машине занимают значительную часть бюджета до учёта контекста |
| Gemma 3 4B Q4_K_M | 3,4 ГБ по каталогу, Gemma Terms of Use | Многоязычная альтернатива с отдельными условиями использования и распространения |

Для Qwen нужно сохранить уведомления Apache 2.0 при распространении весов. Фактическое потребление зависит от движка, CUDA, размера контекста, кэша и фоновой нагрузки. Вес из каталога сравнивается с бюджетом только как предварительный фильтр. Портативный Ollama Windows 0.40.18 для amd64 занимает 1 717 307 988 байт в архиве. [Qwen3 4B](https://ollama.com/library/qwen3:4b), [Qwen3.5 4B](https://ollama.com/library/qwen3.5:4b-q4_K_M), [Qwen3 8B](https://ollama.com/library/qwen3:8b), [Gemma 3 4B](https://ollama.com/library/gemma3:4b), [Ollama 0.40.18](https://github.com/ollama/ollama/releases/tag/v0.40.18).

EFIR передаёт JSON Schema в `format`, повторяет контракт в запросе и проверяет ответ перед записью. В контекст входят первые 24 сцены с порядком, длительностями, ID и ограниченным текстом. Пути, бинарные медиа и заметки в запрос не входят. В приложении задаются `temperature=0`, `think=false`, контекст 8192, выгрузка модели после запроса. [Контракт Ollama](https://docs.ollama.com/capabilities/structured-outputs).

## Корпус из 20 русскоязычных команд

Для каждой строки используйте копию базового проекта. В базовом проекте три сцены «Вступление», «Радио» и «Финал» с визуалом, текстом и субтитрами. Для первых трёх строк используйте пустой проект. Оценка считается только за план с верной схемой и ожидаемым смыслом. Проверяйте, что до подтверждения снимок не меняется. Для каждой команды сохраните предложенный JSON, версию Ollama, имя и digest модели, длительность, RAM и VRAM. Цель — 18 из 20.
