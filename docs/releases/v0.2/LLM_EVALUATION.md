# Проверка моделей Ollama

28 ноября 2026 года установлен и проверен Ollama 0.40.19 с Qwen3 4B Q4_K_M. Корпус выполнен на RTX 4050 через реальный loopback API. Итог по командам и объяснения отклонений приведены в [отчёте AI-приёмки](AI_ACCEPTANCE_REPORT.md).

| Кандидат | Публичные метаданные | Причина для проверки |
|---|---|---|
| Qwen3 4B Q4_K_M | 2 497 293 931 байт слоёв и конфигурации, Apache 2.0, тег `qwen3:4b` | Текстовый кандидат с меньшим объёмом, чем Qwen3.5 4B. Первый для проверки на 6 ГБ VRAM |
| Qwen3.5 4B Q4_K_M | 3 324 173 934 байта слоёв и конфигурации, Apache 2.0, тег `qwen3.5:4b-q4_K_M` | Более свежий кандидат при недостаточном качестве Qwen3. Требует дополнительной проверки памяти и схемы |
| Qwen3 8B Q4_K_M | 5,2 ГБ по каталогу, Apache 2.0, тег `qwen3:8b` | Для сравнения качества на машине с большим запасом VRAM. Веса на целевой машине занимают значительную часть бюджета до учёта контекста |
| Gemma 3 4B Q4_K_M | 3,4 ГБ по каталогу, Gemma Terms of Use | Многоязычная альтернатива с отдельными условиями использования и распространения |

Для Qwen нужно сохранить уведомления Apache 2.0 при распространении весов. Фактическое потребление зависит от движка, CUDA, размера контекста, кэша и фоновой нагрузки. Портативный Ollama Windows 0.40.19 занимает 1 718 318 809 байт в архиве. [Qwen3 4B](https://ollama.com/library/qwen3:4b), [Ollama 0.40.19](https://github.com/ollama/ollama/releases/tag/v0.40.19), [измерения](RESOURCE_BENCHMARK.md).

EFIR передаёт JSON Schema в `format` и проверяет ответ перед записью. В контекст входят первые 24 сцены с номерами, длительностями в секундах и ограниченными текстовыми полями. Приложение отображает номера на ID текущей ревизии и само переводит секунды в кадры. Явное число новых сцен, длительность, точный текст в кавычках и обмен двумя сценами передаются как ограничения схемы. Содержимое файлов и их пути отсутствуют в запросе.

Первый прогон использовал temperature 0, think false, контекст 8192 и выгрузку после каждого ответа. Для сокращения повторов в длинных репликах следующие версии перешли на temperature 0,25, seed 42, repeat penalty 1,12 и ограничения длины полей. Think false, контекст 8192 и немедленная выгрузка сохранены в приложении. Отдельный тёплый замер использует удержание модели на 30 секунд. [Контракт Ollama](https://docs.ollama.com/capabilities/structured-outputs).

## Корпус из 20 русскоязычных команд

Для каждой строки используйте копию базового проекта. В базовом проекте три сцены «Вступление», «Радио» и «Финал» с визуалом, текстом и субтитрами. Для первых трёх строк используйте пустой проект. Оценка считается только за план с верной схемой и ожидаемым смыслом. Проверяйте, что до подтверждения снимок не меняется. Для каждой команды сохраните предложенный JSON, версию Ollama, имя и digest модели, длительность, RAM и VRAM. Цель — 18 из 20.
