# Архитектура v0.2

CLI и Tk открывают проекты через `open_project`. Legacy-редактор использует прежний контракт `Project`. SQLite-редактор работает с теми же операциями сцен и оптимистичными ревизиями `StudioProject`. Ассистент проверяет список команд на копии проекта. Применение плана, ревизия и постановка всех задач происходят одной транзакцией.

В проекте один эпизод и один локальный файл SQLite. Ревизия содержит упорядоченные сцены со стабильными ID и отдельными полями реплики, визуала, озвучки и субтитра. Откат сохраняет прежнее содержимое новой ревизией. Для импорта и истории материалы хранятся по SHA-256. Генеративные результаты добавляются в тот же пул и хранят рецепт отдельно от пользовательских медиа.

Очередь выполняет по одному заданию на проект. Десктоп обслуживает текущий проект и держит один активный фоновый вызов, включая Ollama. Локальный CLI может запустить одну задачу через `work`. Ресурсное ограничение между независимыми процессами для разных проектов отсутствует. FFmpeg принимает неизменяемый снимок и сохраняет MP4 по ID задачи. Для проекта с фоновой дорожкой при упаковке финального MP4 громкость фона понижается, а кадрирование и звуковой кэш сцен переиспользуются. Субтитры v0.2 занимают интервал сцены.

TTS использует только текст сцены, выбранный голос, хеши файлов модели и конфигурации и параметры скорости. Изменения названия, порядка, субтитров и фона не запускают синтез. При изменении реплики или замене выбранного WAV результат запущенного ранее синтеза доступен в задаче. Он становится текущей озвучкой, если реплика и выбранный WAV совпадают со входным снимком. Для осознанной повторной генерации команда `voice --regenerate` меняет ключ кэша.

Создание изображений и видео, персонажи, плагины и передача в редактор через OTIO относятся к v0.3. [Целевая архитектура](../../architecture/TARGET_ARCHITECTURE.md).
