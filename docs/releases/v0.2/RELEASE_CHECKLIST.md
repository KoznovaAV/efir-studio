# Приёмка EFIR Studio v0.2

- [x] JSON v0.1 открывается. Миграция в новый каталог сохраняет старый проект и идентификаторы.
- [x] Неизменяемые ревизии, проверка конкурентного изменения, восстановление.
- [x] Проверка плана, предпросмотр, подтверждение, отклонение и откат.
- [x] Отказ движка оставляет ручной монтаж и экспорт доступными.
- [x] Очередь сохраняется. Устаревшая озвучка остаётся доступной через результат задачи и не выбирается автоматически при конфликте.
- [x] Детерминированные тесты выборочного синтеза и инвалидации кэша.
- [x] Черновик 96 секунд, шесть сцен, фон, субтитры, переносимый MP4.
- [x] Синхронизация черновика с допуском один кадр. Проверены кадровые метки, встроенные субтитры и временной сдвиг шести фрагментов WAV.
- [x] Три контейнерных E2E в режиме без сети с локальными зависимостями.
- [x] Порог 95% строк и проверки Windows, Ubuntu и Docker на коммите реализации. [Прогон GitHub](https://github.com/KoznovaAV/efir-studio/actions/runs/45965439373).
- [ ] Реальный Ollama. Не менее 18 из 20 корректных русскоязычных планов.
- [ ] Реальный Piper. Разборчивость ≥95% и медиана естественности ≥3/5 у двух слушателей.
- [ ] Полный сценарий пилота с реальным чатом и выбранным голосом, включая повтор сцены 2.
- [ ] Измерение CPU, RAM, VRAM и диска для полного AI-маршрута.

Для реальной проверки нужны локальные Ollama, Piper и согласование загрузки моделей. Предложены Qwen3 4B Q4_K_M и голос Denis, переобученный на базе rdh. Результаты тестов адаптеров и прогона с системным голосом подтверждают остальные этапы конвейера. [Проверка Ollama](LLM_EVALUATION.md), [приёмка речи](TTS_EVALUATION.md).
