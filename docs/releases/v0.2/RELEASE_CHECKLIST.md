- [ ] Разборчивость ≥95% и медиана естественности ≥3/5 по двум независимым бланкам. [Протокол](TTS_LISTENING_PROTOCOL.md).

- [x] Измерены CPU, RAM, VRAM, диск и задержки полного маршрута.

- [ ] Повтор без внешней сети на уровне ОС. Сетевой интерфейс Windows во время пилота оставался включён.
