# Ресурсы v0.2

Целевой стенд — Windows 11, Intel Core i5-12450H, RTX 4050 Laptop с 6141 MiB, 16 ГБ RAM. Нативные проверки использовали Python 3.13.16, SQLite 3.50.4, Tk 8.6 и FFmpeg 7.1. Изолированный пакет проверен на Linux Docker Engine 29.8.0 со статическим FFmpeg 8.1.1.

Один прогон 96-секундного черновика в полном профиле 1080×1920 дал 12,324 с на первый экспорт с шестью закодированными сценами и 4,582 с на повтор после замены реплики второй сцены с пятью попаданиями в кэш. Измерен интервал команды `work`, включая запуск Python. Семь системных WAV созданы за 0,427 с через Microsoft Irina Desktop. Итоговый MP4 занял 14 279 369 байт. [Методика пилота](PILOT_REPORT.md).

Во втором прогоне измерялась вся цепочка сценария с шагом около 130 мс для процессов и около 1 с для GPU. Одновременно шли проверки в Docker Desktop. За 39,301 с сумма наблюдавшегося CPU-времени потомков составила не менее 125,17 с, пиковая сумма RSS — 459,31 MiB, а минимальная доступная системная память — 1662,12 MiB при исходных 1948,40 MiB. `nvidia-smi` показывал 0 MiB используемой VRAM. Каталог с исходниками, кэшем, двумя экспортами и переносимой копией занял 154 272 081 байт. На D: до прогона было 61 301 080 064 байта свободного места. Эту системную загрузку следует учитывать при отдельной проверке моделей.

## Приёмочные измерения AI

Квантизация, RAM, VRAM, скорость и место для веса записываются по фактическому прогону модели, а не по пилоту. Снять исходную загрузку системы. Во время холодного и тёплого прогона фиксировать общее потребление GPU через `nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits`, сумму RSS потомков Ollama/EFIR/Piper, доступную RAM, CPU-время, размер исходников, кэша и результатов.

| Ориентир | Статус |
|---|---|
| До 5,5 GiB пиковой VRAM | Ollama не измерен |
| До 10 GiB RAM процессов | Требуется измерение AI-прогона |
| От 2 GiB свободной системной RAM | Требуется измерение AI-прогона |
| Одна фоновая задача студии | Подтверждён по репозиторию очереди и тестам |
